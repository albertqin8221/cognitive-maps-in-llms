## Description

Experiments and analysis code for the paper. The experiment code is built
against tools provided by the sibling `llm-neuroscience-tools` package.

## Installation

Python 3.10 or newer is required. Follow the
[installation instructions](../README.md#installation) to install both packages.
Then, from the combined repository root, enter the paper package directory:

```bash
cd cognitive-maps-in-llms
```

Run the orchestration and figure-generation commands below from this directory.

### Downloading models

Model weights are downloaded separately from the Python packages. Before
running model-dependent experiments, set `LNT_MODELS_DIR` to the directory
where the weights will be stored:

```bash
export LNT_MODELS_DIR=/path/to/models
```

Follow the [model download instructions](../llm-neuroscience-tools/README.md#downloading-models)
in the tools package. Set `LNT_MODELS_DIR` in each shell session or job script that runs the experiments.

## Quickstart: Running GPU tasks

The GPU-dependent steps required to generate the data for the paper are 
partitioned into *tasks*. Each task requires a model to be loaded onto a GPU 
and performs one operation, such as recording activations, running an iterative
pruning procedure, or, most commonly, running a mosaic experiment.

A complete run requires many such tasks due to the various combinations of 
prompt presets and models. This package includes several tools for orchestrating
these tasks in the `tools/` directory.

On Princeton's `Della` cluster, the complete GPU-dependent pipeline can be run as follows:

(1) Create a new orchestration folder and put a manifest in it. For example:

```
orchestration/example_run/example_manifest.toml
```

The supplied example manifest covers the paper's 11 models and 22 prompt presets.

(2) Expand the task manifest into task configuration files:

```bash
python tools/generate_task_configs.py orchestration/example_run/example_manifest.toml
```

(3) Populate the task configurations with runtime estimates and GPU profiles:

```bash
python tools/populate_scheduling.py \
  orchestration/example_run/task_configs --apply-full-run-skip-policy
```

This retains only behavior tasks for alien-name prompts and excludes erasure
and Figure 5 only for `ABC_older_younger_unique_locations_who_is` among non-alien
prompts. Descendant/ancestor and unique-location yes/no prompts are included.

(4) Partition the configuration files into SLURM jobs:

```bash
python tools/plan_slurm_jobs.py \
  orchestration/example_run/task_configs
```

(5) Submit all SLURM jobs:

```bash
for script in orchestration/example_run/job_plan/slurm_scripts/*.slurm; do
  sbatch "$script"
done
```

## Quickstart: Generating figures

First, follow the [data download instructions](../README.md#data-download)
from the combined repository root. Then return to the paper package directory
to run the commands below.

Figures for the paper and supplement are generated by the Jupyter notebooks
in `figures/notebooks/`. By default, they read the downloaded results from
`results/final_run_2026-09-30`, relative to this package directory.
To plot a new run, update `RESULTS_ROOT` in each notebook.

The notebooks can be run interactively or executed together from the paper
package directory:

```bash
find figures/notebooks -type f -name '*.ipynb' \
  -exec jupyter nbconvert --to notebook --execute --inplace {} +
```

The supplementary information also includes analogs of all main-text figures across
several combinations of model and prompt presets. 
These panels can be generated programmatically:

```bash
RESULTS_ROOT="results/final_run_2026-09-30"

# Gemma-27B across supported prompt presets
python figures/scripts/render_main_text_analogs.py --all-prompts \
  --results-root "$RESULTS_ROOT" \
  --output-dir figures/generated/all_panels_gemma_x_all_tasks --overwrite

# All models evaluated in the "family-trees" setting
python figures/scripts/render_main_text_analogs.py --all-models \
  --results-root "$RESULTS_ROOT" \
  --output-dir figures/generated/all_panels_models_x_family_trees --overwrite

# Cross-model scaling panels
python figures/scripts/render_main_text_analogs.py --scaling-only --all-prompts \
  --results-root "$RESULTS_ROOT" \
  --output-dir figures/generated/scaling_panel_all_tasks --overwrite
```

To generate figures for other combinations, use `--models MODEL [MODEL ...]`
and `--prompts PROMPT [PROMPT ...]` to select any supported models and prompt 
presets for which results are available. Missing inputs are recorded in 
`skipped_groups.csv`.
