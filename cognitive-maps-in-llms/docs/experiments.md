# Tasks and Experiments

[README](../README.md)

"Tasks" are the executable units of the pipeline and are specified in the
manifest by a task `kind`; tasks of kind `"mosaic_experiment"` additionally select
an experiment. This section describes the available task kinds and experiments.
Additional implementational details can be found in the supplementary information
accompanying the paper. 

## Tasks

### `recording`

The `recording` task records activation tensors and key-value memories
generated by a model on a set of prompts with varying names and relationship
statements. These data can be later used to compute average activation tensors
and/or  key-value memories, and can also be used to visualize activations by
principal component analysis.

A recording task can be specified in a manifest as follows:

```toml
[[tasks]]
name = "recording"
kind = "recording"
settings = { n_trials = 50, start_seed = 10000 }
```

#### Dependencies

None.

#### Settings

- `n_trials` (required): Number of trials per relational structure.
- `start_seed` (required): First random seed used to sample entity names.

---

### `erasure`

The `erasure` task applies a gradient-based iterative pruning procedure to the
model’s key-value memory. Starting from a “keys-first” mosaic, it estimates the
effect of replacing each retained key or value with its average across prompts
where entity names are resampled. It then iteratively prunes the keys or values
with the smallest estimated effect on model behavior.

An erasure task depends on the output of a `recording` task, which is needed to
compute the average key-value memory used for these replacements.

An erasure task can be specified in a manifest as follows:

```toml
[[tasks]]
name = "iterative_erasure"
kind = "erasure"

[tasks.settings]
start_seed = 20000
n_trials = 10
coarse_fraction = 0.10
fidelity_threshold = 0.90
rewind_multiplier = 2.0
dividing_layer_fraction = 0.5

[tasks.dependencies]
recordings = "recording"
```

#### Dependencies

- `recordings` (required): Output from a completed `recording` task for the
  same model and prompt presets.

#### Settings

- `start_seed` (required): First random seed used to sample entity names.
- `n_trials` (required): Number of trials used to evaluate the pruning objective.
- `coarse_fraction` (default: `0.10`): Fraction of the remaining sites erased
  after each gradient evaluation during "coarse" pruning. Must lie in `(0, 1]`.
- `fidelity_threshold` (default: `0.90`): Normalized fidelity below which
  "coarse" pruning stops. Must lie in `[0, 1]`.
- `rewind_multiplier` (default: `2.0`): Determines how far the trajectory is
  rewound before "fine" pruning resumes. Must be at least `1`.
- `dividing_layer_fraction` (default: `0.5`): Fractional model depth separating
  keys from values in the initial keys-first mosaic. 
---

### `mosaic_experiment`

The `mosaic_experiment` task runs one of the mosaic experiments below.

A mosaic-experiment
task can be specified in a manifest as follows:

```toml
[[tasks]]
name = "exp_2_separability"
kind = "mosaic_experiment"
experiment = "exp_2_separability"
settings = { n_trials = 50 }
```

#### Dependencies

The required dependencies vary by selected experiment.

#### Settings

- `n_trials` (required): Number of trials per condition.

Additional settings depend on the selected experiment.


## Experiments

The available mosaic experiments are summarized below. Each experiment is listed under the corresponding value of the `experiment` field. For more details, see the Methods section of the accompanying supplementary information.

---

### `exp_1_behavior`

Measures unperturbed relational-reasoning behavior across all four assignments
of forward and reverse relations in a three-entity context.

Implementation: [`Experiment_1_Behavior`](../src/cognitive_maps_in_llms/experiments/exp_1_behavior.py).

#### Dependencies

None.

---

### `exp_2_separability`

Tests whether the activation tensor separates entity identity from relational structure by transplanting particular entity-token rows between prompts.

Implementation: [`Experiment_2_Separability`](../src/cognitive_maps_in_llms/experiments/exp_2_separability.py).

#### Dependencies

None.

---

### `exp_3_additivity`

Tests whether entity identity and relational role combine additively in
a "role-swapping" experiment.

Implementation: [`Experiment_3_Additivity`](../src/cognitive_maps_in_llms/experiments/exp_3_additivity.py).

#### Dependencies

None.

---

### `exp_4_retrospective_prospective`

Tests whether the activation tensor represents relationships in a “graph-like” 
form that requires retrospective composition, or instead represents relationships
using a "coordinate-based" representation reflecting the result of composing
relationships prospectively.

Implementation: [`Experiment_4_Retrospective_Prospective`](../src/cognitive_maps_in_llms/experiments/exp_4_retrospective_prospective.py).

#### Dependencies

None.

---

### `exp_5a_bottleneck`

Tests how relational information is distributed between keys and values 
by replacing selected portions of the key-value memory with their
averages over entity names.

Implementation: [`Experiment_5A_Relational_Bottleneck`](../src/cognitive_maps_in_llms/experiments/exp_5a_bottleneck.py).

#### Settings

- `dividing_layer_fraction` (default: `0.5`): Fractional model depth at which
  the `K_THEN_V` and `V_THEN_K` mosaics switch between keys and values.
  Uses the same bounds and rounding convention as the erasure task.

#### Dependencies

- `recordings` (required): Output from a completed `recording` task for the
  same model and prompt presets, used to construct the average key-value
  memory.

---

### `exp_5b_sparse_mosaic`

Measures behavior when only a selected sparse subsets of keys and values are
retained and all other sites are replaced with their averages over entity
names. The buffered condition retains at least twice as many sites as the
resolved 95%-fidelity condition, capped at the initial mosaic size.

Implementation: [`Experiment_5B_Sparse_Mosaic`](../src/cognitive_maps_in_llms/experiments/exp_5b_sparse_mosaic.py).

#### Dependencies

- `recordings` (required): Output from a completed `recording` task for the
  same model and prompt presets, used to construct the average key-value
  memory.
- `erasure_trajectory` (required): Output from a completed `erasure` task for
  the same model and prompt presets, used to select the retained keys and
  values.

---

### `exp_5c_editing`

Tests whether relational representations can be edited by selectively
transplanting retained keys or values. The `NONE` editing location is the
unedited control.

Implementation: [`Experiment_5C_Editing`](../src/cognitive_maps_in_llms/experiments/exp_5c_editing.py).

#### Dependencies

- `erasure_trajectory` (required): Output from a completed `erasure` task for
  the same model and prompt presets, used to select the keys or values to
  transplant.

---

### `exp_s1_positions_rope`

Tests whether the model relies directly on positional information during inference
over the cognitive map by swapping two rows of the activation tensor.

Implementation: [`Experiment_S1_Positions_RoPE`](../src/cognitive_maps_in_llms/experiments/exp_s1_positions_rope.py).

#### Dependencies

None.

---

### `exp_s2_positions_indirect_swap`

Tests whether the model constructs and relies on global positional embeddings
during inference over the cognitive map by using differently shifted versions
of the same prompt. 

Implementation: [`Experiment_S2_Positions_Indirect_Swap`](../src/cognitive_maps_in_llms/experiments/exp_s2_positions_indirect_swap.py).

#### Dependencies

None.
